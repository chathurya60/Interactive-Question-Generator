
# 🧠 Interactive Question Generator

An AI-powered interactive question generator built using **Python, Streamlit, and Google Gemini API**.

The application allows users to generate questions based on a selected topic, difficulty level, question type, and number of questions. Users can answer the generated questions and receive instant feedback and scores.

---

## 🚀 Features

- 🧠 AI-powered question generation
- 📚 Generate questions from any topic
- 🎯 Multiple difficulty levels
  - Easy
  - Medium
  - Hard
- 📝 Multiple question types
  - Multiple Choice Questions (MCQ)
  - True/False
  - Short Answer
- 🔢 Select the number of questions
- ✅ Instant answer validation
- 💡 Explanations for answers
- 🏆 Score calculation
- 📊 Percentage-based performance
- 🔄 Interactive quiz experience
- 🌐 Streamlit web interface

---

## 🛠️ Technologies Used
